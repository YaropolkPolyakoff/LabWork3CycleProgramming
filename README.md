# Помехоустойчивое кодирование — Циклический код (7,4)
## Noise-Resistant Coding: Cyclic Hamming Code

### Описание / Description

Программа реализует **систематический циклический код Хэмминга (7, 4)**:

| Параметр | Значение |
|---|---|
| Длина кодового слова `n` | 7 |
| Информационные биты `k` | 4 |
| Проверочные биты `r = n − k` | 3 |
| Порождающий полином `g(x)` | x³ + x + 1 (двоичное: **1011**) |
| Кодовое расстояние `d_min` | 3 |
| Макс. обнаруживаемых ошибок | 2 |
| Макс. исправляемых ошибок | 1 |

---

### Запуск / Run

```bash
python main.py
```

Требования: Python 3.7+, стандартная библиотека (без внешних зависимостей).

### Алгоритм кодирования / Encoding Algorithm

**Систематическое кодирование:**

1. Принять информационный вектор `m` длиной `k` бит
2. Умножить на `x^r`: сдвиг влево на `r` позиций → `m(x)·x^r`
3. Вычислить остаток: `b(x) = m(x)·x^r mod g(x)` (деление в GF(2))
4. Кодовое слово: `c(x) = m(x)·x^r ⊕ b(x)`

Кодовое слово имеет формат: `[информационные биты | проверочные биты]`

---

### Алгоритм декодирования / Decoding Algorithm

1. Получить принятое слово `r(x)` длиной `n` бит
2. Вычислить синдром: `S(x) = r(x) mod g(x)`
3. Если `S = 0` → ошибок нет
4. Если `S ≠ 0` → найти позицию ошибки по таблице синдромов (однобитные ошибки)
5. Исправить бит по найденной позиции
6. Извлечь первые `k` бит как информационные

### Границы / Coding Bounds

**Граница Хэмминга (sphere-packing bound):**
```
2^(n-k) >= Σ C(n, i)  for i = 0..t
2^3 = 8 >= C(7,0) + C(7,1) = 1 + 7 = 8  ✓  (совершенный код)
```

**Граница Плоткина:**
```
Применима при 2d > n: 2*3 = 6 < 7 — не применима для (7,4,3)
```

**Граница Варшамова-Гильберта:**
```
Σ C(n-1, i) [i=0..d-2] < 2^(n-k)
C(6,0) + C(6,1) = 1 + 6 = 7 < 8  ✓
```

### Математическая основа / Mathematical Background

Код основан на **теореме Хэмминга**: совершенный двоичный линейный код с параметрами
`(2^r − 1, 2^r − r − 1, 3)` исправляет все одиночные ошибки и обнаруживает все двойные.

Для `r = 3`: `n = 7`, `k = 4`, `d_min = 3`.

Порождающий полином `g(x) = x³ + x + 1` — неприводимый над GF(2), делитель `x^7 + 1`.
